github-auto-push — Ava Core → GitHub

Canonical runner:
  /home/ava-core/operations/system-tools/github-auto-push.py

Uses existing:
  /home/ava-core/core_uploader.py
  (token from credentials / GITHUB_TOKEN, same exclude rules)

Behavior:
  - Non-blocking lock so only one push runs at a time
  - Streams core_uploader output live (no silent hang)
  - Default timeout 1200s (20 min); use --timeout 0 for no limit
  - core_uploader clones the repo then walks /home/ava-core — first/full
    runs can take several minutes; that is expected

Cron placement:
  operations/cronologicals/since-last-fire/every-hour/github-auto-push.py
  operations/cronologicals/on-time/HH:00/github-auto-push.py  (00–23)

  python3 /home/ava-core/operations/system-tools/github-auto-push.py

at every boot (slow, network-dependent). Prefer every-hour / on-time slots.
