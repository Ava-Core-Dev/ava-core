Rules that matter

Provider usage object is truth for token counts (not local BPE).
Cost = provider billable amount if you have it; else pricing.json.
Always pass account_id once Desk has a user/session — unattributed calls show as (unattributed).
Never put API keys in context/usage/ or meta_json.
