What ships

The public CDN suite is first-party RootMC software. Live line is … — always read manifest.json, never a hardcoded jar name.

  • Root-Core — license, shared folder, updater, Discord/Slack comms
  • Root-Ava-Core — Ava companion (ensure-installed from the manifest)
  • Root-Times — day clock, playtime, activity
  • Root-Perms — groups & tracks
  • Root-Economy — Gold, Vault, treasury, shops, bonds, loans, tax
  • Root-Essentials — homes, TP, spawn, banners, potions, QoL fees
  • Root-Claims / Root-Territories — personal land and +48 territory buffers
  • Root-Play — ranks, votes, help, new-player road
  • Root-Skills — proportional XP, talents (mcMMO path)
  • Root-Ops — admin, restart, announcer, mapper
  • Root-ItemInfo — /info + world census
  • Root-Gamble / Root-Heads / Root-Haste — mini-games, collectibles, torch
  • RootMC — link, heartbeat
  • RootMC-Official — legacy/optional progression (not required)

Currency is always Gold (G), not dollars. Automated grants debit the Server Reserve — see the Constitution.

Live land (Root-Claims)

Live RootMC is a singular host: play.rootmc.net with Root-Claims only. There is no Towny host and no Claims-world vs Towny pair.

InstallIncludeSkip
Live RootMC / third-party Paper Full suite + Root-Claims + Root-Territories RootMC-Official unless you intentionally want the legacy jar. Vault optional.

Install order

  1. Paper 26.x with outbound HTTPS to api.rootmc.net
  2. Root-Core + product key in plugins/RootMC/root-core.yml
  3. Root-Times → Root-Perms → Root-Economy → Root-Essentials
  4. Root-Play, Root-Ops, Root-Territories, Root-ItemInfo, RootMC
  5. Root-Claims (+ Root-Territories). RootMC-Official last only if you intentionally enable the legacy jar
Shared configs live under plugins/RootMC/, not each jar’s own data folder. Core creates and repairs that folder on enable.

Auto-update

With updater.enabled: true (default), Root-Core polls https://rootmc.net/plugins/manifest.json, downloads newer jars for every installed catalog plugin, prunes older same-plugin jars, and can schedule a restart. Manual: /rootcore update.

  • only-installed: true (default) — update jars already on disk, plus always install updater.ensure (ava-core, times, perms, economy, essentials, claims, territories, play, skills, ops, appreciation, rootmc).
  • only-installed: false — download every manifest entry (full self-install of the public catalog).
