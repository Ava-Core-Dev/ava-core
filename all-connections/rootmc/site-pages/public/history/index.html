RootMC History

Modern RootMC is a 2026 Java / Paper server program developed by Alexrs94, with closed-loop Gold, Discord-integrated operations, and live web tools. Live play is singular play.rootmc.net with Root-Claims. RootMC once experimented with Towny; that is not current topology. The name also has older unrelated lineages; this page keeps those histories separate and clearly scoped.

Modern era (Alexrs94, 2026-)

Development began privately around May 2026. 19 Jun 2026 marks the public brand anchor (rootmc.net registration), and 1 Jul 2026 marks full public open on the fresh map (land was Towny then; live land is Root-Claims).

  • Server model: Java / Paper with closed-loop Gold, Root-Claims land, and treasury-led outflows.
  • Public identity: play.rootmc.net game + rootmc.net web + api.rootmc.net worker API.
  • Ops shape: plugin changelog discipline, live deploy wrappers, Discord bridge, and audit-friendly economy reporting.
  • Data boundary: MySQL is authoritative for bulk game/economy reporting; D1 is retained for auth/link/governance and edge contracts.

Modern RootMC is independent from earlier projects that used the same naming. There is no shared runtime code lineage from those older stacks into the current server architecture.

Pre-current lineages (separate projects)

Three independent histories share parts of the same naming, but they are not the current RootMC server stack:

Lineage A (2015): Root3287 RootMC web + plugin effort

A Spigot/PHP community platform concept (site + plugin integration), aiming at rootmc.com. Development activity is visible in 2015, then stalls. This was tooling/product ambition, not the current SMP lineage.

Lineage B (2020): RootNetwork / AdvancedCraft Bedrock org

A separate Bedrock Nukkit network era with custom lobby and proxy tooling under AdvancedCraft branding. Different edition, different stack, different team from modern RootMC.

Lineage C (name collisions)

Other similarly named projects and public identities exist, including non-Minecraft entities. They should not be merged into RootMC server lore without direct evidence.

Search-confusion note. rootmc.online was registered by a third party in April 2026 and may confuse search results. It is not an official RootMC property.
