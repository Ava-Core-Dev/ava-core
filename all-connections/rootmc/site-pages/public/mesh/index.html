Mesh network

RootMC Mesh is a server-to-server transfer federation — independent Paper hosts (nodes) that recognize each other via api.rootmc.net and move players with vanilla Player.transfer (/goto). It is not client P2P, does not hide join addresses, and does not use BungeeCord or Velocity.

Join each node by its own address (for example play.rootmc.net:25565). The mesh only powers in-game transfers between trusted peers — there is no single “mesh IP.”

Live RootMC is singular play.rootmc.net. Opted-in My Servers get transfer interoperability (/goto) — not a Towny↔Claims production pair.

How players move

  • In-game: /goto <slug> to a trusted peer. Join live play at play.rootmc.net.
  • Peer slugs come from the mesh API — there is no live Towny vs Claims hop.
  • Peer list from GET /api/rootmc/transfer-mesh (server-auth) via Root-Core. Offline fallback: transfer.local-peers in root-core.yml.
  • Transfers are direct host-to-host via vanilla Player.transfer — no proxy in the path.

What syncs (and what does not)

Live RootMC is a singular host. Mesh membership is transport only. RootMC-Official is legacy/optional progression — not current dual-host ops. Community My Servers keep isolated worlds and economies.
