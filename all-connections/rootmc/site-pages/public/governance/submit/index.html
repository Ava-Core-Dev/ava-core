Citizen proposals are created with /proposal <your idea> on the Minecraft server (64 G → Server Reserve). Any linked player can propose; Ava publishes the formal proposal and Discord thread — including catch-up from the official queue if she was offline. Council voters (Vote Shards) cast the weighted votes.

  • Link Discord at /verify and accept the Terms — any linked player can propose
  • Join play.rootmc.net and run /proposal …
  • After Ava publishes: any verified (linked) player can talk in the proposal thread
  • Only voters with Vote Shards in /ec cast votes — +3 G once per proposal when recorded
