# RootMC Vote Sites Opener

Open every official RootMC listing vote page in **one new browser window**. Same links as the homepage and in-game `/vote`.

| OS | Run |
|----|-----|
| **Windows** | Double-click `open-vote-sites.bat` |
| **Linux** | Double-click `open-vote-sites.sh`, or run `./install-linux-desktop.sh` to put **RootMC Vote** on your Desktop |

## What you get

| Site | Reward |
|------|--------|
| Minecraft-MP | 1–20 G in-game when confirmed |
| MinecraftServers.org | same |
| Minecraft Server List | same |
| Minecraft.Buzz | same |
| TopMinecraftServers | same |
| MineRank | same |
| MinecraftList.org | same |
| Planet Minecraft | same |

Gold pays from the **Server Reserve** after Votifier confirms the vote. In-game: `/vote`.

## How to use

1. Unzip this folder anywhere (Desktop is fine).
2. Run the script for your OS (see table above).
3. Complete each site’s captcha / vote form (use the same Minecraft name as in-game).
4. Wait for the in-game / Discord confirmation.

Windows SmartScreen may warn once — **More info → Run anyway**. Linux: mark `open-vote-sites.sh` executable if needed (`chmod +x open-vote-sites.sh`). The scripts only launch your browser with public HTTPS vote URLs; no install, no admin rights.

## Tips

- Most sites allow **one vote per day** (some use a rolling 24h timer).
- **5 listing votes in 24 hours** → ½ transaction tax + ½ death loss.
- Voting also adds **Vote Shard** Council weight — [rootmc.net/vote-shards](https://rootmc.net/vote-shards/) · [Constitution](https://rootmc.net/wiki/constitution/#governance-voting). Buy extra: [rootmc.net/pro/vote-shards](https://rootmc.net/pro/vote-shards/) ($1 = 100, min $0.50).
- Prefer Chrome / Chromium / Edge / Brave so all tabs open in a single new window. Firefox and `xdg-open` are fallbacks.
