RootMC-Official

Legacy/optional progression helper (playtime, skills, votes, perms). Live RootMC is a singular host (play.rootmc.net, Root-Claims) — this jar is not a live Towny↔Claims production pair. Skip it on a single host.

Install (optional / legacy)

  1. Not required for live RootMC. Leave disabled unless you intentionally run extra Paper peers.
  2. Requires Core + shared MySQL peer settings in plugins/RootMC/rootmc-official.yml.
  3. Leave enabled: false until peer + MySQL are ready.
  4. Commands: /rootmcofficial status|sync (ops).

What it is not

Does not replace RootMC, merge economies, or operate a live Towny↔Claims pair. Single-host operators should skip this jar.
