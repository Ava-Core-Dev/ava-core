Root-Essentials

In-house EssentialsX replacement for RootMC — homes, teleport, spawn, banners, potions, and paid QoL commands. Gold economy moved to Root-Economy (Vault + treasury SPI).

What it includes

  • QoL / travel — homes, TP, spawn, warps, RTP, kits, nick/hat, feed/heal/repair (fees → Server Reserve via Root-Economy)
  • Spawn / banners / potions — absorbed modules stay here
  • Economy — owned by Root-Economy (/bal, shops, bonds, loans, tax)

Install + auto-update

  1. Install Root-Core, Root-Perms, then Root-Economy.
  2. Download from the catalog or let Core auto-update from manifest.json.
  3. Optional: keep Vault.jar if other plugins need Vault Economy — Root-Economy registers it.
  4. Gold wallets live on this host. Live RootMC is singular (play.rootmc.net).

Configs (plugins/RootMC/)

  • root-essentials.yml — QoL, fees, teleport, cross-server, kits
  • root-spawn.yml, root-banner.yml, root-potions.yml
  • Economy YAML lives under Root-Economy (root-economy.yml, bonds/loans/shops/upkeep)
