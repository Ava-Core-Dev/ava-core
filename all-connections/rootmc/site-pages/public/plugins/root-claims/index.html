Root-Claims

Personal land claims on live RootMC (play.rootmc.net). Works with Root-Perms — no Vault or LuckPerms required.

Install

  1. Install Root-Core and Root-Perms.
  2. Download from the catalog or let Core pull from manifest.json.
  3. /c is the land command. /t redirects to claims when no other land plugin owns it.
  4. Live RootMC is Root-Claims only — not a Claims-host vs Towny pair. RootMC-Official is legacy/optional, not required.
  5. Player guide: wiki/claims — first area is free; areas 2–3 are wallet-paid. Y < 0 is mining rights. Territory outsiders pay 1 G/block (75/25).
