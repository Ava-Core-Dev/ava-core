What RootMC includes

The same first-party stack on live production — one plugins/RootMC/ folder, one product key, one update channel. Public downloads stay locked to manifest.json.

  • Gold economy — wallets, shops, bonds, loans, mint, treasury, Vault bridge
  • Permissions & ranks — Root-Perms groups/tracks plus purchasable ranks and vote rewards
  • Land — Root-Claims personal areas and +48 territory buffers
  • Time, play & skills — day clock, playtime, AFK, new-player road, Root-Skills XP/talents
  • Ops — admin tools, graceful restart, announcer, mapping helpers
  • Sync & web — account link, stats heartbeat, item census, live site APIs
  • Auto-update — Root-Core polls manifest.json and keeps jars current

From empty Paper to live in five steps

  1. Paper 26.x — host you control, outbound HTTPS to api.rootmc.net
  2. Root-Core — free product key, set server-name + product-key in root-core.yml
  3. Drop the suite — Times, Perms, Essentials, Play, Ops, Territories, Root-Claims, RootMC
  4. Start once — Core binds cloud id, creates shared configs, registers My Servers
  5. Stay current — /rootcore update or wait for the scheduled pull from the CDN

Live RootMC land is Root-Claims only. RootMC-Official is legacy/optional network progression — not a live Towny↔Claims pair.
