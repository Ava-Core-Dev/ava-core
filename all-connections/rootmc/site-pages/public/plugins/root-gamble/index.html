Root-Gamble

Gold-staked mini-games — payouts debit the treasury (never mint wallets). Needs Root-Core + Root-Economy. /coin Ava always accepts when Server Reserve is 0+ and she can cover — she has a gambling problem.

Download jar

Install

  1. Install Root-Core and Root-Economy first.
  2. Drop root-gamble-*.jar; remove older same-plugin jars.
  3. Config: plugins/RootMC/root-gamble.yml.
  4. MySQL via shared plugins/RootMC/database.yml.

In-game

  • /coin Ava <amount> — Ava auto-accepts if /reserve is 0+ and she can cover. Stake is capped to reserve. Pays from Server Reserve. No click needed; works offline.
  • /coin <player> <amount> — player duel (accept / deny).
  • /roulette · /hilo · /lotto · /dice · /gamble
