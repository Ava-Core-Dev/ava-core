Root-Perms install guide

First-party groups, tracks, and Bukkit permission attachments on shared MySQL. Replaces LuckPerms for Root-Ranks and loan limits. Registers Vault Permission when Vault is present.

Install

  1. Install Root-Core and configure shared MySQL in plugins/RootMC/database.yml.
  2. Drop root-perms-<version>.jar into plugins/ (loads before Essentials / Play). Delete older root-perms-*.jar copies.
  3. Configure plugins/RootMC/root-perms.yml — default group, player track (same ids as root-ranks.yml), optional server-id.
  4. Root-Perms alone is enough for live RootMC — no LuckPerms required. Vault is optional (permission bridge when present).
  5. Restart Paper. Check /rootperms status.

Commands

/rootperms status|user|group|reload (aliases /rperms, /perms) — permission rootperms.admin.

Suite deps

Install before Root-Essentials and Root-Play. Ranks and rank-based loan caps use Root-Perms groups — not LuckPerms.
