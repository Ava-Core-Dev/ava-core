Root-Market

In-game /market browser for the RootMC Gold economy — categories, live buy/sell quotes from player chest shops (and virtual listings), trending sell multi. Stock still lives in Root-ChestShops; this GUI is the catalog.

Download jar Root-Economy → Root-Core →

Install

  1. Install Root-Core, Root-Economy, and Root-ChestShops.
  2. Drop root-market-*.jar into plugins/; remove older same-plugin jars.
  3. Config lands under plugins/RootMC/ on first enable (trending.* for spyglass hub).
  4. Restart Paper after jar install.

Player use

  • /market — browse categories; item lore shows BUY/SELL G/ea and G/stack plus Dynamic Sell Value
  • Hub spyglass — top highest/lowest sell multi vs worth (config trending.*)
  • Buying from virtual listings deposits to the buyer’s item bin
