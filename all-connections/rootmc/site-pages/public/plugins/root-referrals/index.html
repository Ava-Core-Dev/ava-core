Root-Referrals

Personal referral codes (/root), claim window, Discord + playtime qualification, and treasury-funded Gold for referrers. Player explainer: rootmc.net/referrals.

Install

  1. Requires Root-Core (MySQL via Core). Soft: RootMC (Discord link), Root-Times (playtime), Root-Economy / treasury SPI, PlaceholderAPI.
  2. Drop root-referrals-*.jar into plugins/ (or let Root-Core auto-update from the manifest).
  3. Config: plugins/RootMC/root-referrals.yml — gates, reward amounts, milestones, messages.
  4. Restart Paper after jar install. Schema creates root_referral_* tables on first enable.

Defaults

  • Qualify: Discord linked + 3 h playtime; claim within 48 h of first join
  • Pay: 75 G to referrer (0 to recruit); lifetime cap 2000 G
  • Milestones: 5 / 15 / 30 qualified → +50 / +100 / +200 G
  • Depth 1 only — no multi-level residual

Commands

  • /root (/refer, /referrals) — hub
  • /root code · /root claim <code> · /root info · /root tree · /root top
  • /root admin … / /rootreferrals reload — staff
