Root-ChestShops

Chest-based player shops on the RootMC Gold economy, plus optional virtual item bins (/item, My Storage). Special listings include BONDED_NOTE and APPRECIATION_TOKEN (Appreciation Tokens — not plain sunflowers). Install after Root-Core + Root-Economy.

Download jar Root-Economy → Root-Core →

Install

  1. Install Root-Core and Root-Economy.
  2. Drop root-chestshops-*.jar into plugins/; remove older same-plugin jars.
  3. Config lands under plugins/RootMC/ on first enable (needs working database.yml for virtual storage).
  4. Restart Paper after jar install. Look for virtual-storage MySQL ready in logs.

Player commands

  • Chest shops — create/stock as documented in the economy shops guide
  • /item — deposit / withdraw virtual bins; open My Storage
  • List for sale from bins; cancel listings; buyers can purchase virtual stock via /market

Special item keys

  • BONDED_NOTE — Root-Economy bond certificates (not plain paper)
  • APPRECIATION_TOKEN — Root-Appreciation sunflower tokens (not plain sunflower); tradeable in chest + virtual shops
  • Mint-peg gold resources (nugget/ingot/block/ore) remain forbidden in shops
