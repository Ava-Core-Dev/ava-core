Root-ItemInfo

World item census — /info shows scanned totals for any material, optional average Gold value, and a mint-peg gold summary. Periodic scans cover online inventories and loaded containers.

Install

  1. Drop root-iteminfo-*.jar into plugins/ (or let Root-Core auto-update from the manifest).
  2. Config: plugins/RootMC/root-iteminfo.yml — keep scan.enabled: true for startup + periodic scans.
  3. Optional: RootMC for MySQL census push; Root-Essentials / RootMC for average Gold values.
  4. Restart Paper after jar install.

Commands

  • /info — held item (/iteminfo, /ii)
  • /info <material> — e.g. diamond, gold_ingot
  • /info gold — scanned gold stacks + mint-peg G
  • /info top — top materials by count (staff)
  • /info reload — reload + rescan (staff)

Scope

Counts cover online inventories, ender chests, loaded containers, and optional ground items. Unloaded chunks are not visible — treat totals as a live scanned snapshot, not a full world map.

Permissions

  • rootiteminfo.use — use /info (default: true)
  • rootiteminfo.admin — /info top (default: op)
  • rootiteminfo.reload — reload (default: op)
