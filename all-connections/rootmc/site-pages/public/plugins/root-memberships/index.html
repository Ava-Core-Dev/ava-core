Root-Memberships

Syncs cloud Pro / Lifetime (including paid pro_paid_until) to a configurable permission group (default pro for the [Pro] badge). In-game /donor · /pro · /lifetime show full perks + Stripe checkout. Development funding gate: 8 paid Pro or $40/mo (best case $200/mo; award Pro never counted). Also handles tradeable Pro vouchers from Stripe one-time purchases: claim via /vault, right-click to redeem.

Install

  1. Requires Root-Core. Soft: RootMC (cloud link status), Root-Perms or Vault.
  2. Drop root-memberships-*.jar into plugins/ (or let Root-Core auto-update from the manifest).
  3. Config: plugins/RootMC/root-memberships.yml — memberships, group names, sync interval, voucher materials/lore.
  4. Seed the pro group in Root-Perms if you use the default badge.
  5. Restart Paper after jar install. Upload both root-memberships and rootmc when voucher vault delivery is needed.

Commands

  • /donor · /pro · /lifetime — full perks, features, Stripe checkout, and paid-Pro development gate (8 / $40 / $200)
  • /memberships status — config + your cloud flags + sync (staff)
  • /memberships reload — reload YAML
  • /memberships sync — force sync for yourself
