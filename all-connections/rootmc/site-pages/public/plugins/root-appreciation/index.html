Root-Appreciation

Sunflower Appreciation Tokens, global supply stats via /thanks, daily /bonus, right-click redeem into a weighted 247-item catalog, and player-shop trading (APPRECIATION_TOKEN). Player guide: rootmc.net/thanks.

Install

  1. Requires Root-Core (MySQL via Core). Soft: Root-Economy (bonus Gold), Root-Gamble (Free Lotto Ticket redeem).
  2. Drop root-appreciation-*.jar into plugins/ (or let Root-Core auto-update from the manifest). Pair with root-chestshops ≥ 1.8.0 so tokens trade as APPRECIATION_TOKEN.
  3. Config: plugins/RootMC/root-appreciation.yml — streak days, cooldown, messages, redeem gate. Weighted catalog ships inside the jar (appreciation-rewards.yml).
  4. Restart Paper after jar install. Schema creates root_appreciation_* tables on first enable.

Defaults

  • Token item: sunflower + custom name/lore + PDC (distinct from plain sunflower in shops)
  • /bonus Day 1–5: 1–5 tokens + 5–25 G (treasury); ~20 h cooldown; miss ~48 h → reset to Day 1
  • Join MOTD reminds when bonus is available
  • Each confirmed /vote grants 1 token + 1 digital Vote Shard (same number as listing votes) + 1–20 G. Token lore and /thanks point at /vote for the full vote note. Physical /ec shard items are not used for Council math.
  • Redeem: right-click token (air preferred) or /thanks redeem — needs 1 empty slot; server-wide broadcast
  • /thanks give is console only (not usable by OP in-game)
  • Tradeable in chest shops / /market / virtual bins as APPRECIATION_TOKEN

Commands

  • /thanks (/appreciation, /apptoken) — issued / redeemed / supply + vote totals
  • /thanks give <player> <amount> — console only
  • /thanks redeem [amount] — redeem token(s); or right-click a token (not while clicking shop signs/chests)
  • /bonus — claim daily streak reward
  • /voteshard · /voteshard power · /voteshard ava — digital EC + paid shards; Ava’s Council seat is a locked 25% synthetic share (no extra EC mint)
  • /vote (Root-Play) — full vote note: gold, tokens, shards, Council share
  • /thanks reload — admin reload config
