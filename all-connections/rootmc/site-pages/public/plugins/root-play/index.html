Install

  1. Install Core, Root-Perms, and Root-Essentials first.
  2. Remove old root-ranks, root-rewards, roothelp jars.
  3. Configs: root-ranks.yml, root-rewards.yml, roothelp.yml, root-road.yml under plugins/RootMC/.
  4. Perms track group ids must match root-ranks.yml.
  5. Welcome / road copy can use {server} from Core server-name.
