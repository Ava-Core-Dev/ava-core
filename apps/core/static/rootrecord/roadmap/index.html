Foundation

Platform & account

Shared sign-in, billing, API workers, and cross-app services on rootrecord.info.

  • Shipped
    Per-product API shards

    Dedicated rootrecord-api-* workers: account, business, weather, Kilauea, token, and goals.

  • Shipped
    Account hub & billing

    Sign-in, subscription status, Stripe billing, and My Apps on the web.

  • Shipped
    Web SSO for product dashboards

    Member web apps at product subdomains with shared RootRecord sessions.

  • Shipped
    Shard cutover for web & crons

    Product web apps, Discord/Global Updater, and scheduled jobs run on dedicated shards. Primary has no crons in repo; rootrecord.info auth, earn, and farms routes proxy to the account shard.

  • Shipped
    Inactive-account cleanup cron

    Scheduled cleanup runs on the account API shard (45 8 * * *), not primary.

  • Shipped
    Root Record Global Updater

    Discord bot for per-product release feeds, /root channel setup, and verified Roots balance commands. Add to Discord

  • In progress
    Retire api.rootrecord.info hostname

    Play Store Android builds still default to that URL, which terminates at legacy rootrecord-primary (weather paths forward to the weather shard). Delete the Worker only after re-binding the route and shipping APKs with shard URLs.

  • Shipped
    Account verification & recovery

    One-time proof by email or Discord; password reset with email codes; account status on Account.

  • Shipped
    Sensitive-change confirmation

    15-minute email or Discord re-confirmation before password/email changes, Discord unlink, account deletion, wallet link/unlink, Roots transfers, custodial withdraw, and SOL swaps.

  • Exploring
    Shard-scoped Stripe & push routes

    Trim duplicated cross-product routes so each worker only mounts what its app needs.
