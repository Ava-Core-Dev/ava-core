What Root Record infrastructure is

Three brands, one solar host. Mixing the hostnames is how things break.

BrandJobPublic home
Root Record Real-world system of record: solar, weather, Kīlauea, Goals, accounts, consumer apps, this wiki. rootrecord.info (marketing + wiki) · rootrecord.online (live dashboard / blogs)
Ava Ivy Runtime on the OptiPlex: FastAPI origin, crons, heartbeat, Discord/Slack/Telegram, local Ollama. avaivy.cloud/wiki/ · live desk avaivy.cloud/ · status APIs at rootrecord.info/ava/status
RootMC Sibling Minecraft network. Consumes host-power (battery / CPU / solar) as Gold rules. Not this domain’s product. rootmc.net · join play.rootmc.net · API api.rootmc.net

Edge rule locked in the architecture docs: Cloudflare is proxy, DNS, Workers, D1, Pages, and offline fallback. Scheduling and truth live on the desk.
