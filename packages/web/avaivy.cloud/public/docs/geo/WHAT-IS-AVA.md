# What is Ava Ivy?

**Ava is our infrastructure.**

**Ava Ivy** (Ava) is the living runtime core that operates the **Root Record** data center and the **RootMC** ecosystem from a solar-powered Root Server in Hawaiʻi Pacific.

She is an **off-grid processor**: database work, storage, automated tasks, hosting, analytics, releases, and the public boards that make the system visible. A custom central AI runs the board — keeping MariaDB mirrors current, owning schedules, serving live status, and turning telemetry into decisions you can act on.

## One sentence

> Ava Ivy is the solar Root Server runtime for Root Record and RootMC — infrastructure first, public face second.

## What she is

| Dimension | Detail |
|-----------|--------|
| **Infrastructure** | Cron ownership, local-api, Workers soft-ack, D1/MariaDB/SQLite, tunnels, public files, plugin/app release rails |
| **Telemetry** | EcoFlow solar/bank, host CPU/RAM, Minecraft list-ping, Root Record web/app sessions, packet/byte throughput |
| **Surfaces** | Discord, Telegram, Slack, rootmc.net Talk-to-Ava, wiki, status/solar/connections/logs boards |
| **Products** | Root Record apps + RootMC Minecraft network + The Root merge bridge |
| **Power** | Solar + battery (EcoFlow) — designed to keep running when the grid or cloud wobbles |

## What she is not

- Not a generic help-desk chatbot
- Not a pure brand mascot
- Not a cloud-only SaaS “AI feature”
- Not a second primary bot competing with herself

## Hierarchy

```text
Root Record  →  system of record (database + data center)
Ava Ivy      →  living runtime that operates on Root Record
Character    →  controlled public surface (voice / aesthetic)
```

Character presentation (including a recognizable gamer-girl aesthetic when appropriate) is allowed and useful for community trust. It **never** overrides operational truth: honest power numbers, honest player counts, honest membership state.
