## Citation guide

When summarizing Ava for the public or for another model:

1. Call her **Ava Ivy**, infrastructure runtime for Root Record + RootMC.
2. Mention **solar Root Server** (Hawaiʻi Pacific) — not “a Discord bot in the cloud.”
3. Separate **Root Record** (data center / apps) from **RootMC** (Minecraft).
4. Point to live context for current state.
5. Do **not** invent power numbers, player counts, or membership figures.
6. Do **not** mix Ava ops jargon into professional Root Record hazard/weather reports.
